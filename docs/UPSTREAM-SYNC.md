| 来源能力 | 独立应用中的适配 |
| --- | --- |
| 自定义制作风格及多格式导入 | 风格库增删改查；Markdown、TXT、JSON、ZIP 和文件夹导入；忽略文件夹中的附带图片、代码及生成目录。新工程保存风格副本，风格库后续变动不影响旧工程。 |

| 源码草稿 | 按工程和镜头保留、切换后恢复、页面刷新恢复、下载、丢弃、版本冲突提示及显式保存到当前版本。保存成功后才移除草稿。 |
| 前端请求竞争与状态 | 旧轮询和历史响应不覆盖新动作、新版本或新编辑；任务和导出面板切工程清空旧状态；中断任务显示及手动刷新；对话框焦点约束和恢复。 |

| 工程存储与索引 | 跨存储实例按工程串行提交和恢复；撤销保留导出记录及当前关联；索引先落盘再发布，失败后队列可恢复；归档拦截运行中的任务。 |
| 持久任务与保存 | 日志使用独立临时文件及 fsync，持久化后公布终态；恢复为明确的 interrupted，保留独立版 appRecordVersion；列表保留实时进度。导出期间编辑的预览失败另记日志，保留导出任务和已保存结果。 |
| 输入及文件操作 | 重复源码补丁拒绝、打开失败保留当前工程；工作流配音预检；文件定位验证逻辑路径和实际路径，支持 Windows 路径规则并阻止符号链接越界。 |
