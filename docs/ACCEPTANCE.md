存储测试注入了提交前失败和提交后投影中断，确认前者没有部分写入，后者重开由完整 canonical head 修复。Undo/Redo 覆盖全部源码、旁白、音轨和资产引用；生成任务多镜变更可作为一次撤销。旧 revision 源码在删除镜头和移动源码目录后仍可读取，保证导出输入一致。

原生模型测试实际经过 `/models`、`/chat/completions` 本机 HTTP 协议和应用凭据服务。初稿一次提交为 v1，保留手改镜头标题；讨论不修改工程。模拟 HTTP 503 后回合标为失败，点击重试产生一个新的完整版本。SSE、截断输出、读取回执、有限修复和显式图片授权由模型/对话回归覆盖。

实际媒体为 **640×360、24/1 fps、6 秒、144 帧、H.264 + AAC**。使用真实 Chrome/Canvas 捕帧、FFmpeg 编码与合成验收音；ffprobe 回读、FFmpeg 全部解码通过，原生视频播放器 currentTime 前进且无媒体错误。导出运行器检查关键帧倒序与冷加载一致性。音轨用于验证制作路径，不代表配音质量或人工听音验收。

桌面场景的系统 renderer PID 与编辑器不同，场景没有 Node 或桌面 bridge；私有项目文件和无 token HTTP 请求被拒绝。实际执行无限循环场景后，十秒 watchdog 显示无响应，编辑器和服务仍可调用；将源码修复后，通过限定的 iframe 调试通道中止执行并重载，预览检查完成。

打包应用保留 Electron framework 的相对符号链接，运行不需要源码目录。手工添加三镜并拖动重排，真实预览和界面源码保存通过；未存源码阻止返回首页并保留草稿，顶部显示未存状态。实际工具检查能识别 `/bin/false` 的不可用结果，修正浏览器路径后恢复。关闭前立即修改镜头标题，退出保存后重启读回同一内容。包中的 fflate 实际完成工程备份与独立导入。

## 本地记录

`artifacts/acceptance-v02/verification.json` 为原生详细记录，`package-verification.json` 为迁移应用包记录；PNG 保存首页、设置、工作台、播放器、紧凑窗口与实际可见中帧。`yingliu-app.mp4` 为真实本地媒体。`docs/acceptance-summary.json` 保留可提交的脱敏摘要与媒体 SHA256。运行数据、凭据、日志、中间帧和大型应用包不进入 Git。

## 验证的实际边界

单元/存储测试使用 renderer stub，不能替代真实制作检查。原生和包检查实际调用浏览器及编码器，但使用确定性测试网关；**真实 DeepSeek 创作质量为 NOT_CHECKED**，需要用户在应用内配置自己的服务并发送创作请求后验证。

图片传输的开关、授权、范围、字节、尺寸与安全路径由生产协议测试验证，未用真实视觉模型评估图片理解质量。六份 recipe 是创作约束资料，继续保留 design_proposal。

完整人工观看/听音、机器断电注入、另一台机器、Windows/Linux、签名公证与公开发行为 NOT_CHECKED。当前并发范围是原生单实例、单工程串行队列；没有跨进程工程锁、版本/素材垃圾回收或逐帧断点续渲。

## 复验

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run verify
npm run package:app
node scripts/verify-package.mjs
```

需已安装可检测的 Chrome/Chromium、FFmpeg 和 ffprobe。测试每次使用新的隔离数据目录，退出只清理自己启动的应用及制作进程；打包检查的合成窗口退出对话框采用测试自动回答，避免失败后阻塞清理。
