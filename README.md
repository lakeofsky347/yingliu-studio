# 映流 Studio

映流是一个本地视频创作应用。先填写影片简报，再与自己的模型讨论、构建初稿；也可以从空白节点图开始，亲手安排镜头、画面和声音。两条路径共用同一份工程，随后可以预览、导出 MP4、备份和继续编辑。

当前版本 **0.2.0**。应用拥有独立 Electron 窗口、项目首页、凭据、工程历史和制作任务，不依赖 DeepSeek Harness 或父工作区。

## 打开应用

macOS 本机应用：`artifacts/映流 Studio.app`。源码运行需要 Node.js ≥ 22.18：

```sh
npm ci
npm start
```

应用包包含 Electron、界面、工程服务、ZIP 备份模块及浏览器驱动。逐帧捕获需要本机 Chrome/Chromium，编码需要 FFmpeg、ffprobe。首页显示检测结果；工程工作台的「运行环境」可选择或填写可执行文件绝对路径。缺少渲染工具时仍可编排分镜、导入素材和编辑源码。

浏览器开发入口：`npm run dev`，默认 `http://127.0.0.1:19430`。浏览器模式的模型密钥仅存在于服务进程内存，重启后需要重新填写；桌面模式通过 Electron safeStorage 加密保存。

## 完整制作流程

1. 在「我的影片」点击「新建影片」，填写名称、主题、目标片长、输出规格和创作方向。选择「从空图开始」可以完全手动制作；选择「让模型构建初稿」会先保留简报，再开始可取消的创作请求。
2. 「模型设置」填写 DeepSeek 或自定义 OpenAI 兼容接口的 Base URL、模型 ID、API Key。默认地址为 `https://api.deepseek.com/v1`，默认模型为 `deepseek-chat`。保存后密钥不回显；支持替换、删除与连接检查。
3. 对话中「讨论」交流结构与方案；「构建初稿」生成分镜和可编辑场景；「修改」调整当前镜头或整片。失败、取消和意外中断有持久状态，可重试。模型先规划和校验整次修改，再提交一个工程版本。
4. 在工作台添加、拖动、连接和重排镜头，编辑文字、颜色、运动、时长和素材关联。分镜图采用线性镜头主链；未完成连线也可保存，预览和导出时会提示缺少的连接。
5. 导入 PNG/JPEG/WebP 图片、文字与音频，设置旁白、音乐、音效、增益和片段位置。可直接编辑每镜 HTML/CSS/JS；源码未保存时会阻止离开编辑位置，保存后执行实际场景检查。「恢复上次可用」和持久撤销可用于修复。
6. 刷新预览、逐帧查看并导出视频。导出保留输入快照、素材哈希及媒体检查；「任务记录」查看进度、失败原因和可重试任务，「导出成片」播放不同工程版本的成片或打开文件。
7. 返回首页可搜索、打开、重命名、复制、归档和恢复影片。「修改历史」支持重启后的撤销、重做；「备份工程包」保存 `.yingliu`，导入时创建新的独立工程。

备份包含当前分镜、创作简报、场景源码与素材，不包含对话、完整撤销历史、任务日志或已导出视频。复制工程也不继承旧对话和导出。归档保留原文件，可以恢复。工程包限制单文件 24 MiB、素材合计 64 MiB、压缩包和解压总量 96 MiB。

## 模型与创作方向

支持兼容 `/chat/completions` 的普通 JSON 和 SSE 响应，可设置温度、输出 token、超时和上下文预算。创作镜头数量按需求为 1–12，可添加、删除、重排并修改素材、音轨、输出参数与场景代码。普通对话不创建工程，也不触发预览。

模型密钥只进入本应用的凭据服务，不写入工程、对话、备份或任务参数。图片默认仅发送元信息；只有模型能力与图片发送均启用，且用户在本轮明确选择图片并授权上传时，才发送所选 PNG/JPEG/WebP 像素。存在数量、尺寸、字节和镜头素材范围限制。

工作包的六种创作方向保留 recipe 的配色、构图与运动说明，并保存选择、版本及输出 profile 到简报。recipe 保持 `design_proposal`：它们指导模型创作，不等同六套已验证的固定视觉模板。

## 保存与恢复

同一工程的写操作排队并检查 `expectedRevision`。工程及全部镜头源码组成不可变版本，以一个原子状态指针提交；`project.json` 与镜头文件是可修复的投影。请通过应用修改工程，不要直接覆盖已打开工程的投影文件。

关闭前应用会请求编辑器保存，保存失败可继续编辑；运行中的模型或制作任务会询问是否取消后退出。重启将未完成任务标记为中断，保留最后已提交版本。制作任务可从当前工程重试；没有逐帧断点续渲。场景代码失去响应会显示有界错误，原生「重新加载画面」可重置本应用的无特权画面进程。

## 开发与验收

```sh
npm run typecheck
npm test
npm run build
npm run verify
npm run package:app
node scripts/verify-package.mjs
```

`verify` 使用隔离数据目录和实际 localhost 模型测试网关，操作真实 Electron 界面、检查工程流转，实际捕帧、编码、完整解码并播放六秒带合成验收音的 MP4。它不请求付费供应商，不代表真实 DeepSeek 创作质量或 TTS 质量。结果在 `artifacts/acceptance-v02/`；源码、测试和脱敏验收摘要提交远端，凭据、项目、日志和大型媒体不提交。

当前包为 macOS arm64、本机临时签名，尚未公证；Chrome/FFmpeg 仍由用户运行环境提供。跨机器安装、Windows/Linux 发行与真实模型创作验收分别待验证。没有云渲染、视频输入、多人协作或通用节点市场。
