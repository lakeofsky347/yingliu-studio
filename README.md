# 映流 Studio（`yingliu-studio`）

**开箱即用的本地独立视频创作桌面应用：简报对话、分镜节点图、可编辑画面、多模态生成与本地 MP4 导出。**

`yingliu-studio`（当前版本 **0.5.0**，已对齐基座 1.0.0 工作台核心交互）是映流系列的**独立桌面工作台版**。它自带 Electron 桌面窗口、项目首页、本地加密凭据库、工程历史与备份恢复，**不依赖 DSH Desktop 或外部宿主**。

> **映流三仓库对照（选哪个？）**
>
> | 仓库 | 形态 | 适合场景 |
> | --- | --- | --- |
> | `yingliu-video-studio` | DSH Desktop 插件（v1.0.0） | 已在使用 DSH，希望在会话旁直接打开工作台并联动 DSH 会话／子代理 |
> | **`yingliu-studio`（本仓库）** | 独立 Electron 桌面应用（v0.5.0） | 不依赖 DSH，偏好「简报 → 对话／分镜 → 精修 → 导出」人为掌控的独立本地工作台 |
> | `yingliu-agent` | 智能体版独立应用 + CLI（v1.1.0） | 希望导演智能体自主规划、执行与质检，或使用无头 `yingliu` CLI 自动化出片 |
>
> *与 `yingliu-agent` 可同时安装：两者使用独立的应用数据目录、默认工程目录（`~/Documents/YingliuProjects`）与开发端口（`19430`），互不冲突。*

## 快速开始

### 环境要求
- **运行源码**：Node.js ≥ 22.18
- **预览渲染与导出 MP4**：本机安装 Chrome / Chromium、FFmpeg 与 ffprobe（首页会自动检测，也可在工作台 **运行环境** 中手填可执行文件绝对路径；缺少工具时仍可编排分镜、管理素材与编辑源码）

### 启动方式

```bash
# 1. 安装依赖
npm ci

# 2. 启动桌面应用（Electron 独立窗口，模型密钥经系统 safeStorage 加密保存）
npm start

# 或启动浏览器开发模式（默认 http://127.0.0.1:19430，密钥仅存进程内存）
npm run dev
```

### 打包独立应用

```bash
npm run package:app
```

| 平台 | 构建产物与入口 |
| --- | --- |
| macOS | `artifacts/映流 Studio.app`（保留本机 ad-hoc 临时签名） |
| Windows | `artifacts/yingliu-studio-win32-<arch>/yingliu-studio.exe`（请整目录移动） |
| Linux | `artifacts/yingliu-studio-linux-<arch>/yingliu-studio.sh`（可按需运行包内 `install-desktop-entry.sh` 安装菜单入口） |

> 如需显式校验目标平台，可传 `--platform=<win32|darwin|linux> --arch=<x64|arm64>`；目标需与当前宿主和 Electron 运行时一致。

## 核心功能一览

### 1.0.0 对齐的新版工作台
- **双色主题**：默认深色界面，支持通过顶部 **更多操作 → 切换到浅色工作台 / 切换到深色工作台** 在深色与 **Marble White 浅色模式** 间切换并自动持久化。
- **监视器、画布与分栏**：监视器与时间线共享播放位置，支持空格播放、帧号定位、逐帧查看与导出当前帧 PNG；分镜画布带缩略图卡片、端口连线、缩放与小地图；宽屏下支持分栏对照。
- **1.2 秒防抖后台自动预览**：修改参数保存后约 1.2 秒后台准备预览，仅更新预览状态指示，不置全局锁、不打断连续键入。
- **安全交互与历史**：时间线支持拖拽与 `Alt + ← / →` 调序；重新生成已有分镜需确认，删除镜头提供即时撤销 Toast，删除资产会二次确认；**修改历史** 支持跨重启的持久撤销／重做。

### 对话创作与多会话协作
- **三种意图模式**：在左侧 **创作对话** 中切换 **讨论**（不改动工程）、**构建初稿** 与 **修改**（可限定当前选中镜头或整片）；对话结果先整轮规划校验，再以单个版本原子提交。
- **结构化智能体与计划**：支持 `story.json` 创作计划与审批、角色库与一致性打分、项目级费用上限、尾帧承接、配音对齐及导出前质检（详见 [docs/AGENT.md](docs/AGENT.md) 与 [docs/ROADMAP-0.5.md](docs/ROADMAP-0.5.md)）。

### 自定义视频风格库 & 源码草稿恢复
- **视频风格库**：通过顶栏或首页打开 **风格库**，自由新建、编辑、删除风格，或导入 **Markdown、TXT、JSON、ZIP 与风格文件夹**（只提取文本，绝不执行包内代码）。新建影片选用后随工程保存独立副本，修改或删除库中条目不影响已有影片。
- **源码草稿持久化**：在底部 **前端源码** 面板编辑每镜 HTML / CSS / JS，草稿按工程与镜头自动本地留存；切换镜头、面板或重启后均可恢复，遇到新版本时提示对照处理，未保存草稿会阻止误预览与误导出。

### 多模型中心与多模态制作
- **灵活模型路由**：快速配置默认兼容 DeepSeek／自定义 `/chat/completions` 接口；在 **模型中心** 可同时保存多个连接与模型，分别为导演、场景代码、视觉检查、生图、生视频、配音、音乐、音效分配角色。
- **多协议与异步模板**：内置 Chat Completions、Images Generations、映流媒体网关 v1（[协议说明](docs/media-gateway-v1/README.md)）、Speech 以及可配置异步模板（通义万相、可灵、火山方舟／即梦、Runway、Replicate、ElevenLabs 等）；未接入外部生图／音效模型时可由代码动画与本地合成兜底。
- **人工采纳与隐私边界**：参考图默认仅发送元信息，仅在能力开启且本轮显式勾选授权后才上传所选图片；远程生成的图片与视频先下载检查为「待采用」，点击采用后才写入工程。
- **本地视频与混音**：支持小文件直接导入或大视频本地路径导入（默认单文件上限 512 MiB，可在环境设置中下调），每镜头支持裁剪、倍速、铺满与原声提取；音频面板支持旁白、背景音乐、音效与淡入淡出混音。

### 项目首页与 `.yingliu` 工程包
- 首页支持搜索、重命名、复制、归档／恢复影片；归档保留文件且运行中任务会阻止误归档。
- 支持流式导出与导入 `.yingliu` 工程包（包含分镜、简报、源码与素材；不含对话、任务日志与已导出的较大视频；兼容 v1/v2）。

## 典型制作路径

1. **建片与定风格**：在首页点击 **新建影片**，填写片名、创作简报、目标片长、输出规格，并选择内置创作方向或 **自定义视频风格**；可「从空图开始」或「让模型构建初稿」。
2. **配置模型**：打开 **模型设置** 填写接口与 API Key（密钥不回显、不写入工程或备份；连接检查不发起计费生成）。
3. **编排与精修**：通过对话、分镜画布、时间线、属性面板、协作制作或前端源码打磨镜头；在资产库与声音面板补充图片、视频与音轨。
4. **预览与导出**：在监视器检查画面与混音，点击 **导出视频**，在 **导出成片** 中播放各版本 MP4 或打开本地文件。

## 数据安全与当前边界

- **原子版本与写队列**：同一工程的写操作串行排队并强制校验 `expectedRevision`，工程与源码以不可变版本快照提交。请始终通过应用修改工程，勿手动覆写运行中的投影文件。
- **凭据隔离**：模型密钥仅存于本应用凭据服务，绝不写入工程文件、对话记录、日志或导出包。Linux 无系统钥匙环时不保存新密钥，但仍可手动编辑工程。
- **当前限制**：发行包目前为本机临时签名／未公证、未制作系统安装器；本地模拟网关与协议验收不等同真实付费供应商的创作质量验收；不支持云端渲染与多人实时协同。
